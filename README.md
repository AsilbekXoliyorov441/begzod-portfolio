# Begzod — shaxsiy portfolio

Yosh web-dasturchi Begzodning shaxsiy portfolio sayti: men haqimda, oilam, ustozim, do‘stlarim, loyihalarim va hobbiylarim.

## Bo‘limlar

- **Bosh sahifa** — tanishuv, statistikalar va portret
- **Men haqimda** — qisqacha ma'lumot va ko‘nikmalar
- **Oilam** — eng yaqin insonlarim
- **Ustozim** — bilim va ilhom manbai
- **Do‘stlarim** — birga o‘tgan lahzalar
- **Loyihalarim** — asosiy loyiha: [DOMUS — premium uylar](https://my-project-liart-xi-11.vercel.app)
- **Hobbiylar** va **Bog‘lanish**

## Imkoniyatlar

- Scroll paytida [AOS](https://michalsnik.github.io/aos/) animatsiyalari
- Rasmlarni bosib kattalashtirish (lightbox, klaviatura bilan boshqarish)
- Telefon, planshet va kompyuterga moslashuvchan dizayn, mobil menyu
- Faol bo‘limni menyuda belgilash va scroll progress chizig‘i
- `prefers-reduced-motion` sozlamasiga hurmat

## Texnologiyalar

HTML5 · CSS3 · JavaScript · AOS · Vercel

## Tuzilma

```
├── index.html
├── css/style.css

├── images/          # portret, oila, ustoz va do‘stlar rasmlari
├── vendor/aos/      # AOS kutubxonasi (lokal nusxa)

```

## Ishga tushirish

Hech qanday o‘rnatish shart emas — `index.html` faylini brauzerda oching.
